# PixelMate 使用说明

## 选择内置宠物

1. 打开“宠物图鉴”。
2. 从内置猫、狗、鸟类角色中选择一只宠物。
3. 点击“设为桌宠”，宠物会立即出现在透明桌面窗口中。

当前版本只开放内置宠物，自定义图片入口暂时关闭。

## 设置角色

在“陪伴空间”设置名字、对用户的称呼、陪伴身份和性格。角色可以是朋友、虚拟男友、虚拟女友、学习搭子或自定义身份。

抚摸、喂食和送礼会改变亲密度、心情、活力和经验。当前养成系统不会因为长时间未打开应用而惩罚用户。

## 配置 AI

在“服务配置”填写：

```text
API Base URL: https://服务商地址/v1
API Key:      用户自己的密钥
模型名称:     服务商提供的模型 ID
```

点击“测试连接”。项目不提供调用额度，产生的费用由用户与服务商结算。

## 天气

默认提供 Open-Meteo 示例地址，不需要 API Key。用户也可以填写兼容天气服务地址和自己的 Key。当前版本使用经纬度查询，不会持续跟踪位置。

## 音乐

选择本地音频文件即可播放。请只使用自己有权播放的内容。关闭应用后需要重新选择本地音乐。

## 开机自动启动

进入“服务配置”，在“开机自动陪伴”中主动打开开关。PixelMate 会注册为当前用户的登录启动项，下次登录 Windows 或 macOS 后直接显示桌宠，不会弹出角色管理器。

开关默认关闭，也可以随时从同一位置撤销。宠物选择、养成进度和 API 配置保存在本机，重新开机不需要再次填写；请勿在公共电脑启用或保存生产环境密钥。
